# Craps Game

A Python implementation of the classic casino dice game **Craps**, designed to demonstrate foundational programming concepts in Python.

## Game Rules

1. **First Roll:**
   - **Win:** Rolling a sum of **7** or **11** results in an immediate win.
   - **Loss:** Rolling a sum of **2, 3, or 12** ("Craps") results in an immediate loss to the casino.
   - **Goal Set:** Rolling **4, 5, 6, 8, 9, or 10** sets that number as your **"goal"**.

2. **Goal Phase:**
   - Keep rolling the dice until either:
     - You roll your **goal** number again (**You Win**).
     - You roll a **7** (**Casino Wins**).
